## Honest verdict on "Stubbed"

**Strengths (real):**
- The best concept fit on the list. The product's core mechanic (one stub per watch, stub counts, ticket UI) and the name are the same idea, so we never need to explain the name.
- It is a verb in the past tense, so it reads as proof. "Stubbed it", "3× stubbed", "Stub it" as the button label. This gives it copy leverage that no other candidate has.
- It is 7 letters, spelled the way it sounds, and easy to say on TikTok.

**Weaknesses (real, and not fatal):**
1. **Negative connotation**: "stubbed my toe". It will produce a few jokes. Brand copy can use it on purpose ("Stubbed. Painless."). Low risk.
2. **Crowded "stub" namespace in our own category**: AMC Theatres' **"AMC Stubs"** loyalty programme is a well-known mark in movie exhibition, and small apps already exist (MyStubs, Stubstack, TicketStub, My Stub). "Stubbed" as one word is different from these, but a **trademark clearance search (USPTO/EUIPO, classes 9, 41, 42) is required before public launch**. Medium risk.
3. **Developer jargon**: to engineers, "stubbed" means a fake test double. This is irrelevant to consumers, but it makes SEO a little noisier. Low risk.
4. **TV fit**: a ticket stub is a cinema object. The metaphor still works if every watch counts as a "ticket", so we make TV cards tickets too (for example "S2 · E5" printed as the seat and row). Low risk if the design carries it.
5. **Domain**: the exact `.com` is probably taken or parked. Plan on `stubbed.app` / `getstubbed.com` / `stubbed.tv`. **Not verified.**

**Recommendation: keep "Stubbed" as the brand.** It scores highest (53/65), and its weaknesses can be managed. The launch gate is a clean trademark search against AMC Stubs. If that search fails, fall back to **Punched** (51/65), which keeps the whole verb system ("Punch it", "punched 3×", punch-card streaks). Use **"Admit One"** as a UI motif (it is printed on every ticket card), not as the brand.

Tagline options: "Proof you watched." · "Only the good stuff." (a nod to the ≥6.5 curation) · "Every watch gets a stub."
